# PMCosmetics Empire – Unified Edition (7 + 11 Countries)

## Objective
Automatically merge the 7-country version with the 11-country version into one unified structure using GitHub Copilot.

## Copilot Tasks
1. Scan all folders and files in both versions.
2. Create a unified structure named: pmcosmetics-empire-unified
3. Merge duplicated pages and components.
4. Create one global catalog + sub-catalogs per country.
5. Standardize HTML/CSS/JS structure.
6. Fix broken imports, missing assets, and inconsistent naming.
7. Generate missing code automatically.
8. Push all changes to the main branch.
