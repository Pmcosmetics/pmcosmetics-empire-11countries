# 📚 دليل الإعداد - PM.Cosmetics\n\n## المتطلبات الأساسية\n\n- **Node.js** 18+ و **npm** أو **yarn**\n- **PostgreSQL** 14+\n- **Redis** 7+\n- **Docker** و **Docker Compose** (اختياري)\n- **Git**\n\n## 🚀 خطوات الإعداد\n\n### 1️⃣ استنساخ المشروع\n\n```bash\ngit clone https://github.com/shukrypeter79-max/pmcosmetics.git\ncd pmcosmetics\n```\n\n### 2️⃣ تثبيت المتعلقات\n\n```bash\n# تثبيت جميع المتعلقات (workspaces)\nnpm install\n```\n\n### 3️⃣ إعداد متغيرات البيئة\n\n```bash\n# نسخ ملف البيئة النموذجي\ncp .env.example .env.local\n\n# ملء البيانات:\nDATABASE_URL=\"postgresql://pmcosmetics:pmcosmetics123@localhost:5432/pmcosmetics\"\nJWT_SECRET=\"your_super_secret_key_here\"\nAPI_PORT=3001\nNEXT_PUBLIC_API_URL=http://localhost:3001\nSTRIPE_PUBLIC_KEY=\"pk_test_...\"\nSTRIPE_SECRET_KEY=\"sk_test_...\"\n```\n\n### 4️⃣ تشغيل قاعدة البيانات و Redis\n\n#### خيار أ: استخدام Docker\n\n```bash\ndocker-compose up -d\n```\n\nهذا سيشغل:\n- **PostgreSQL** على `localhost:5432`\n- **Redis** على `localhost:6379`\n\n#### خيار ب: التثبيت اليدوي\n\n```bash\n# macOS\nbrew install postgresql redis\nbrew services start postgresql\nbrew services start redis\n\n# Linux\nsudo apt-get install postgresql redis-server\nsudo systemctl start postgresql\nsudo systemctl start redis-server\n```\n\n### 5️⃣ إعداد قاعدة البيانات\n\n```bash\n# الانتقال إلى مجلد قاعدة البيانات\ncd packages/database\n\n# تثبيت Prisma CLI\nnpm install -g prisma\n\n# دفع الـ schema إلى قاعدة البيانات\nnpm run push\n\n# أو تشغيل migrations\nnpm run migrate\n\n# توليد Prisma Client\nnpm run generate\n```\n\n### 6️⃣ تشغيل خوادم التطوير\n\n```bash\n# من جذر المشروع\nnpm run dev\n```\n\nسيشغل تلقائياً:\n- ✅ **Backend API** على http://localhost:3001\n- ✅ **Frontend Web** على http://localhost:3000\n\n### 7️⃣ تشغيل تطبيق الموايال (اختياري)\n\n```bash\ncd apps/mobile\nnpm install\n\n# iOS\nnpm run ios\n\n# Android\nnpm run android\n\n# Web\nnpm run web\n```\n\n## 🌐 الوصول إلى التطبيقات\n\n| التطبيق | الرابط | الوصف |\n|---------|--------|-------|\n| 🛍️ **المتجر** | http://localhost:3000 | واجهة العميل |\n| 🔌 **API** | http://localhost:3001 | خادم التطبيق |\n| 📊 **Prisma Studio** | http://localhost:5555 | إدارة قاعدة البيانات |\n\n## 📱 تسجيل حساب تجريبي\n\n1. اذهب إلى http://localhost:3000/register\n2. ملء بيانات التسجيل\n3. اضغط \"إنشاء حساب\"\n4. سيتم تحويلك تلقائياً إلى صفحة الدخول\n\n## 🧪
