# المساهمة في PM.Cosmetics

شكراً لاهتمامك بالمساهمة في مشروع PM.Cosmetics! 🎉

## 📋 إرشادات المساهمة

### 1. Fork the Repository
```bash
git clone https://github.com/shukrypeter79-max/pmcosmetics.git
cd pmcosmetics
```

### 2. Create Feature Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes
- اتبع معايير الكود الموجودة
- أضف تعليقات للأكواد المعقدة
- استخدم TypeScript

### 4. Commit Message Format
```
[type]: description

Examples:
- [feat]: Add new payment gateway
- [fix]: Fix cart calculation bug
- [docs]: Update API documentation
- [style]: Format code
- [test]: Add unit tests
```

### 5. Push and Create PR
```bash
git push origin feature/your-feature-name
```

ثم أنشئ Pull Request على الفرع الرئيسي.

## 🎨 معايير الكود

- استخدم TypeScript دائماً
- اتبع ESLint rules
- اكتب تعليقات واضحة
- أضف tests للميزات الجديدة

## 🧪 الاختبار

```bash
npm run test
npm run lint
```
