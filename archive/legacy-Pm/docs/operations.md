# PM Cosmetics Hub — تشغيل وفحص

## تشغيل الواجهة محليًا

من جذر المستودع:

```bash
python -m http.server 8080 -d app
```

ثم افتح `http://localhost:8080`.

## فحص الأساس

يتطلب Node.js 20 أو أحدث:

```bash
npm run validate
```

الفحص يتحقق من الملفات الأساسية، هوية المشروع، الأسواق، قواعد حماية الأسرار، ووجود واجهة storefront أولية.

## قاعدة التشغيل

لا تُنشر بيانات الكتالوج أو الدفتر إلى الواجهة قبل المرور بعملية validation مخصصة للبيانات.
